About Automatic Backups

This site's database runs on Supabase's free tier, which does not include automatic scheduled backups — that's a paid feature on Supabase's paid plans. To stay completely free, this site does not rely on it.

Instead: download a manual backup above whenever you make significant changes (e.g. after adding a batch of new products), and keep the file somewhere safe. A monthly habit is reasonable for a shop this size.
